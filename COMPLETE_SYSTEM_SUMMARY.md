## 🆘 Support / Troubleshooting

**Dashboard not syncing?**
- Refresh page
- Check that you're on same device (or add Firebase for cross-device)
- Check browser's localStorage (F12 → Application)

**Himanshu doesn't see task?**
- You created it, he refreshes his view
- Check that both of you are logged in
- Try refreshing both browsers

**Task data lost?**
- Data is in browser's localStorage
- Works across browser refreshes (persists)
- If you clear browser data, it resets (let me know if you need Firebase backup)

**Need real-time sync across devices?**
- Current: Works same device only (localStorage)
- Cross-device: Need Firebase setup (contact me, 30 min setup)
