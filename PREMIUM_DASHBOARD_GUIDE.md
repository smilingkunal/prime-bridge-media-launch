## 🎯 Design System

### **Color Palette**
```
Primary:        #667eea (vivid blue-purple)
Secondary:      #764ba2 (deep purple)
Success:        #10b981 (green)
Warning:        #f59e0b (amber)
Danger:         #ef4444 (red)
Text Primary:   #1a1a2e (near-black)
Text Secondary: #6b7280 (gray)
Background:     #f9fafb (off-white)
Border:         #d1d5db (light gray)
```

### **Typography**
```
Headings:   Poppins, weights 700–800
Body:       Inter, weights 400–500
Labels:     Inter, weights 600–700 (uppercase)
Sizes:      36px (H1), 24px (H2), 18px (H3), 14px (body), 13px (labels)
```

### **Spacing**
```
Padding:    28px (cards), 16px (meta rows), 14px (inputs)
Gap:        20–24px (between cards), 12px (inline)
Margins:    40px (main sections), 32px (vertical flow)
```

### **Shadows**
```
Hover:      0 12px 24px rgba(0, 0, 0, 0.08)
Normal:     1px solid #e5e7eb (borders instead)
Login:      0 20px 60px rgba(0, 0, 0, 0.3) (prominent)
```
