## Programmatic SEO Page Structure (Template)

Every page you write follows this:

```
1. **Hero section** (150 words)
   - Problem statement (the gap customers face)
   - 3-word promise
   - CTA: "Get a Free Audit"

2. **Why this matters** (200 words)
   - Data point (from GSC / rank math analytics)
   - Stat that shocks (e.g., "85% of [niche] miss this")
   - Emotional hook

3. **5 Key Steps** (500–800 words, 100–150 each)
   - H2 per step
   - 1 image per step
   - 1 internal link per step (to pillar pages)

4. **Common Mistakes** (200 words)
   - What NOT to do
   - Why it fails

5. **FAQ Schema** (300 words, 5–8 questions)
   - Structured data for featured snippets
   - Answers 50–100 words each

6. **CTA + Lead Form** (100 words)
   - "Get Your Free [Niche] Audit"
   - Form: Name + Phone + Business Name
   - On submit: Telegram notification + Google Sheet update

7. **Internal Links** (5–10 links)
   - To pillar pages (e.g., "Local SEO Pillar")
   - To related service pages
   - To previous blogs on same niche
```

---

## Blog Post Structure (Template)

Every blog follows this:

```
1. **Intro** (100–150 words)
   - Hook (question or stat)
   - What they'll learn
   - How long to read

2. **Main Content** (600–1000 words)
   - 3–5 sections (H2 each)
   - 1–2 images
   - Bullet points for scannability

3. **Actionable Takeaway** (50 words)
   - "Start today: [one action]"
   - Directly applicable, no fluff

4. **CTA** (50 words)
   - Link to relevant page
   - "Want [outcome]? Read our full guide on [topic]"

5. **Related Posts** (internal links)
   - 2–3 links to related blog posts
   - Anchor text = target keyword
```

## Quality Checklist (Before Publishing)

**Every page/blog must pass this before you click "Publish":**

### SEO Quality
- [ ] Focus keyword in title (first 60 chars)
- [ ] Meta description (150–160 chars, includes focus keyword)
- [ ] H1 includes focus keyword (exactly once)
- [ ] Focus keyword in first 100 words
- [ ] Rank Math score ≥70
- [ ] Readability grade: College or lower (Rank Math metric)
- [ ] Internal links: ≥3 to pillar pages
- [ ] External links: ≥2 to authority sources
- [ ] Image alt text: descriptive, not keyword-stuffed

### Content Quality
- [ ] No fluff (every sentence adds value)
- [ ] No AI-isms ("Delve into", "In today's world", "Without further ado")
- [ ] Real data/stats (not made up or outdated)
- [ ] Actionable (reader can do something after reading)
- [ ] On-brand tone (professional but friendly)

### Technical
- [ ] Schema markup added (FAQ or HowTo or LocalBusiness)
- [ ] Images optimized (<100KB, WebP format if possible)
- [ ] CTA button colors match brand (#004CB1)
- [ ] Form works (test submission)
- [ ] Links all return 200 (internal + external)
- [ ] Mobile preview checked (Rank Math tool)

### Before Clicking Publish
- [ ] Read it once out loud (catch awkward phrasing)
- [ ] Check for broken links (run Rank Math link checker)
- [ ] Verify image file names are descriptive
- [ ] Double-check phone number + email in footer
