## Red Flags (Watch For)

| Flag | Action |
|---|---|
| Page/blog missing by 2 PM Monday | Call immediately. Ask what's blocking. Extend to 5 PM if needed. |
| Rank Math score <70 | Tell him which element to fix (usually: meta description, keyword placement) |
| Social calendar missing | Has he read the brief? Resend with clarification. |
| Same mistake twice | Train him on that specific issue (e.g., "Always put focus keyword in first 100 words") |
| MIA / no response | Text @kunaldahiya on Telegram directly. Get back on track. |

## Blocker Resolution Flowchart

```
Himanshu messages: "Blocker!"
         ↓
Is it a content question?
    YES → Answer in Telegram (2 min)
    NO → Go to next
         ↓
Is it a WordPress/Rank Math issue?
    YES → Remote share screen, fix (10 min)
    NO → Go to next
         ↓
Is it unclear brief?
    YES → Clarify brief, resend (5 min)
    NO → Go to next
         ↓
Is it a gap in training?
    YES → Teach right thing, he continues (15 min)
    NO → Go to next
         ↓
Extend deadline to EOD same day
Regroup Friday
```
